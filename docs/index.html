Your developer toolbox,
entirely offline.

26 everyday tools — JSON, YAML, XML, CSV, hashing, JWTs, encoders — in one native macOS app. Nothing you paste ever leaves your machine: the app makes no network calls at all, so it's safe for production payloads, tokens, and customer data.

Why use it

The parts that apply to every tool in the app, not just one.

Nothing leaves your machine

No network code anywhere in the app, and no third-party dependencies to audit. Paste a real access token or a customer record without thinking twice.

Live, as you type

Output updates on every keystroke — no "run" button. Tools with two directions (Beautify/Minify, JSON→CSV/CSV→JSON) share one input and switch with a toggle.

Syntax highlighting

JSON, HTML, XML, CSS and YAML output is colored by token type, with separate light and dark palettes that follow the app theme.

Collapsible tree view

Switch JSON, YAML or XML output from text to a foldable node tree — expand and collapse node by node, or all at once. Stays fast on large documents.

Full-screen inspection

Blow either pane up to near-screen size when a payload is too big for the split view. Output scrolls and stays selectable without being editable.

Out of your way

Lives in the menu bar with no Dock icon. ⌘C / ⌘V / ⌘A work as expected, with a brief highlight on whichever pane just changed.

Install

About a minute, start to finish.

  1. Download the disk image Grab m_tools-0.1.0.dmg from the latest release — or jump to the release notes to see what changed first.
  2. Drag the app to Applications Open the .dmg and drag m_tools.app into your /Applications folder.
  3. Open it the first time with right-click → Open m_tools is signed with an internal certificate rather than a paid Apple Developer ID, so on first launch macOS will say it "cannot be opened because the developer cannot be verified." Right-click (or Control-click) the app icon, choose Open, then confirm Open in the dialog. You only need to do this once — double-clicking works normally from then on.
  4. Find it in the menu bar m_tools has no Dock icon by design. Look for its icon in the menu bar at the top right of your screen; click it and choose Show m_tools to open the window, or Quit m_tools to exit.
If right-click → Open doesn't appear to work Some Mac configurations quarantine downloaded apps more aggressively. Open System Settings → Privacy & Security, scroll to the Security section, and click Open Anyway next to the m_tools message, then launch the app again.

On a managed Mac, or without admin rights

If step 2 asks for an admin password you don't have, you're a standard user and /Applications isn't writable by you. Two ways around it, neither of which needs a password:

Ask IT to push it through MDM There's a .pkg built for exactly this. An MDM installs it as root, so there's no admin prompt and no "cannot be verified" warning — and updates arrive the same way, silently. Point them at docs/deployment.md in the repo — the package is attached to every release alongside the .dmg.
Or install it just for yourself ~/Applications is a per-user app folder that belongs to you, so no authentication is involved. Paste this into Terminal after downloading: 
mkdir -p ~/Applications
hdiutil attach ~/Downloads/m_tools-*.dmg
cp -R /Volumes/m_tools/m_tools.app ~/Applications/
hdiutil detach /Volumes/m_tools
xattr -dr com.apple.quarantine ~/Applications/m_tools.app
open ~/Applications/m_tools.app
The last-but-one line removes the "downloaded from the internet" flag that triggers the verification warning — the same decision as clicking Open Anyway, just scoped to this one app instead of changing a system setting.

Updating

There's no auto-updater yet — updates are a re-download, which takes about as long as the original install.

  1. Check which version you have The version is shown on the release you downloaded. If you're unsure, run this in Terminal: 
    mdls -name kMDItemVersion /Applications/m_tools.app
  2. Compare against the latest release The current version is 0.1.0 — see all releases, or the release notes below.
  3. Quit, replace, reopen Quit m_tools from the menu bar first, then drag the new app into /Applications, replacing the old one. Because every release is signed with the same internal certificate, macOS treats it as the same app — you won't have to do the right-click → Open dance again.
Want to know when there's a new version? Open the repo and click Watch → Custom → Releases. You'll get a notification whenever a release is published, and nothing else.

The initial rollout: 26 tools, the shared two-pane workspace, and the CSV editor.

  • 26 tools across Format, Convert, Inspect, Generate, and Encode — see the full list above.
  • Searchable sidebar with collapsible category sections; the selected tool fills the main pane.
  • Syntax highlighting for JSON, HTML, XML, CSS, and YAML output, with matched light and dark palettes.
  • Collapsible tree view for JSON, YAML, and XML — fold node by node, or expand/collapse everything at once.
  • Expand to full screen for either the input or output pane.
  • CSV Editor — open, edit, and save CSV files in a grid with a pinned header, inferred column types, configurable delimiter, and a double-click cell dialog that pretty-prints JSON values.
  • Keyboard shortcuts — ⌘C copy, ⌘V paste, ⌘A select all, with a highlight pulse on the pane that changed.
  • Light and dark themes, toggled from the header.
  • Menu bar app — no Dock icon; show or quit from the status item.
